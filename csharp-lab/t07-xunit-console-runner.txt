# t07 — the xUnit suite, run by xUnit's own console runner

dotnet test could not reach its testhost in this sandbox (t06 —
the testhost process ran, but the console's loopback connection
to it never landed, at a 90-second and then a 300-second timeout).
That is a limit of this build machine, not of the code. The
xunit.runner.console package — version 2.9.3, the suite's own
xUnit version, fetched from nuget.org — runs the same compiled
test assembly in one process, with no socket to connect:

$ dotnet exec xunit-runner/tools/net6.0/xunit.console.dll \
    StockReport.Tests/bin/Debug/net10.0/StockReport.Tests.dll -nocolor
